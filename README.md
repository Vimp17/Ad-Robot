# Замер скорости скачивания

Небольшой скрипт на Python измеряет скорость загрузки файла с указанного адреса. Он выполняет **10 последовательных GET-запросов**, дожидается завершения каждого, затем печатает среднее время запроса, общий объём скачанных данных и среднюю скорость.

## Требования

- Python 3.10 или новее
- Доступ в интернет

Дополнительные библиотеки устанавливать не нужно.

## Запуск

Скачайте `net_speed.py`, откройте терминал в папке с файлом и выполните:

```bash
python net_speed.py "https://example.com/path/to/large-image.jpg"
```

На некоторых системах команда Python называется `python3` или `py`:

```bash
python3 net_speed.py "https://example.com/path/to/large-image.jpg"
py net_speed.py "https://example.com/path/to/large-image.jpg"
```

Пример с тестовым файлом (сервер должен разрешать прямое скачивание):

```bash
python net_speed.py "https://speed.hetzner.de/100MB.bin"
```

## Параметры

```text
python net_speed.py URL [--requests N] [--timeout СЕКУНДЫ] [--chunk-size БАЙТЫ]
```

- `--requests` / `-n` — число последовательных скачиваний; по умолчанию `10`.
- `--timeout` — таймаут одного запроса; по умолчанию `60` секунд.
- `--chunk-size` — размер блока чтения; по умолчанию `65536` байт.

Например, выполнить 5 запросов с таймаутом 30 секунд:

```bash
python net_speed.py "https://example.com/large.jpg" --requests 5 --timeout 30
```

Скрипт считает байты, реально прочитанные из ответов, и суммарное время скачивания. Средняя скорость выводится в десятичных МБ/с (`1 МБ = 1 000 000 байт`) и Мбит/с. Скорость зависит от сервера, сети, кэша и повторных скачиваний; это измерение загрузки именно указанного URL, а не универсальный тест интернет-канала.

Если сервер вернёт ошибку, потребует авторизацию или не позволит скачать файл, скрипт напечатает ошибку и завершится с ненулевым кодом.
